# ECHOES — 5v5 Over-the-Shoulder Tactical Shooter (Prototype)

Single-player prototype: you + 4 bot teammates vs 5 enemy bots. Every combatant
fields an AI **Echo** companion (20 entities on the field).

**Play:** https://xmrmathx.github.io/echoes/

## Controls
- **Mouse** look · **LMB** fire · **RMB** aim (ADS)
- **WASD** move · **Shift** sprint · **Space** jump · **C** crouch · **R** reload
- **Q** summon/reposition Echo (flash pulse) · **1/2/3/4** Echo mode
  (Seek / Cover / Guard / Free Roam) · **G** set Echo guard waypoint

## Round flow
- **Phase 1:** hold the neutral Mid-Core uncontested for 60s to secure it.
- **Phase 2:** the enemy Main Base Core becomes vulnerable — destroy it to win.

Desktop keyboard + mouse. Three.js r160 is vendored in `vendor/` (no CDN needed).
